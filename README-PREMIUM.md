## 🎨 Design-Variablen

Das Design verwendet CSS Custom Properties:

```css
--color-gold: #FFD700          /* Haupt-Gold */
--color-gold-light: #FFE55C    /* Helles Gold */
--color-gold-dark: #B8860B     /* Dunkles Gold */
--color-black: #000000         /* Haupthintergrund */
--glass-bg: rgba(255,255,255,0.05)  /* Glaseffekt */
```

Anpassungen können direkt in der `:root` Sektion vorgenommen werden.
